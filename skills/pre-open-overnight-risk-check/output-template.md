## 三个问题

- 数据：数据足够、仍新且口径一致 / 检查不完整
- 结构：结构尚可，可继续观察 / 结构转弱 / 结构破坏 / 本次未评估结构 / 尚不可上移保护参考
- 执行：按现行规则可以执行所写计划 / 计划按现行规则不可执行 / 检查不完整
- 总结论：

较早的合成例把核心项齐备写成「完整」。那个词只等于上面的「数据足够、仍新且口径一致」，不是放行，也不是新买入已经通过。缺失、过期、冲突或所需口径未解决时，总结论必须包含「检查不完整」，不得写「无风险」或「无重大新闻」。
