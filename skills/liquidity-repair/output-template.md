# 流动性修复检查记录

空白模板，配合 [SKILL.md](SKILL.md) 使用。共享字段和三个问题以 [交易记录](../../docs/trade-record.md) 为准。事实、推断和缺口见 [证据约定](../../docs/evidence-contract.md)。括号里的说明不要留在正式记录中。

正式记录不写账户、总资金、其他持仓、密钥或本机路径。这不是下单指令。保护参考不是保证成交的价格，也不是必须守到才可以考虑退出的价位。

本模板把三件事分成三节：入场或观察、已有仓位的持有或退出、复盘。一次检查只填写当次要做的那一节，并保留另外两节为「本次不填写」或指向已经追加过的旧节。不要把三节写成同一句结论。

## 共享字段

- 记录编号：
- 规则版本：`2026-11-14.3` 或当次快照实际使用的版本
- 本次阶段：入场或观察 / 持有或退出 / 复盘
- 持有窗口：
- 价格假设：
- 证据截止（as-of，原始时区 / Asia/Shanghai）：
- 实际交付时间（原始时区 / Asia/Shanghai）：
- 当前可卖数量：未知 / 数量。未知不要编造
- 保护参考：尚未建立 / 当前值。依据的已完成结构和证据时间：
- 未关闭缺口：阻断性 / 非阻断。没有就写「无」
- 对应计划快照版本：只引用，不修改快照
- 调用方给出的数据最长龄期：未填写 / 本次填写

## 三个问题

三问分开写。阻断性缺口不得引出新买入已经通过，也不得把执行结论写成可以执行。

- 数据：数据足够、仍新且口径一致 / 检查不完整。受影响的判断：
- 结构：结构尚可，可继续观察 / 结构转弱 / 结构破坏 / 本次未评估结构 / 尚不可上移保护参考
- 执行：按现行规则可以执行所写计划 / 计划按现行规则不可执行 / 检查不完整
- 总结论：
- 阻断性缺口：
- 非阻断缺口：

数据缺失、过期、冲突，复权口径空白，或近 20 日等必需口径仍未解决时，总结论必须包含「检查不完整」，不得写成风险已经排除。板块涨跌幅或最小申报单位未填时，卖出可行性是「检查不完整」，不得写成可以执行。

## 证据条目

每条核心数据复制一块。不适用的字段写「不适用」。

- 名称：
- 来源 URL 或官方页面标识：
- 检索时间：
- 数据 as-of 时间：
- 会话：常规收盘 / 盘后 / 期货 / 休市报价 / 其他（写明）
- 单位：
- 复权或公司行为口径：空白则成交均价与价格的比较为「检查不完整」
- 摘录或数据片段：
- 规则版本：
- 来源状态：已打开直接页面 / 当次确已打开的授权源 / 只有摘要或缓存 / 缺失 / 来源冲突 / 本次没有独立复核

## 入场或观察

本次不做就写「本次不填写」。

- 卖压：只用上一交易日融资等滞后证据。缺融资则这一判断为「检查不完整」，不要写成钝化已经成立
- 回踩承接：
- 隔夜冲击是否仍在恶化：
- 失效位置是否已经写下：
- 剩余空间是否还值得承担 T+1、跳空、费用和融资成本：
- 新买入：本次不评估 / 条件未齐 / 不得在阻断性缺口下写成已经通过

集合竞价或第一波反弹本身不是确认。

## 已有仓位的持有或退出

本次不做就写「本次不填写」。继续持有不等于这个价格仍适合新买入。

- 这一轮修复是否仍在继续：
- 退出理由有没有增强：
- 保护参考：维持 / 上移 / 尚不可上移保护参考。上移要写旧值、新值、证据时间和依据
- 首次跌破：若已确认的保护参考被跌破，可以提醒。不把两根短周期 K 线当成推迟这次提醒的理由
- 跳空或跌停：不得假设能在保护参考价成交

## 持有与现在卖出的情景比较

本次不做就写「本次不填写」。字段含义只以 [情景比较](../../docs/hold-sell-compare.md) 为准。这一节不改计划快照，也不代替上面的结构判断。

- 追加编号和证据截止：
- 现在卖出的价格假设：类别（已观察 / 调用方假设 / 压力情景）、来源、检索时间、as-of、会话、单位、复权口径
- 上沿与下沿：同样写类别和出处。概率省略就写「未给出」
- 若给出概率：类别是调用方假设、压力情景、经验估计或已观察来源。经验估计不是已测得胜率
- 股数、可卖数量、板块涨跌幅是否已写明、最小申报单位、T+1、跳空或涨跌停是否使所写价格不能成交：
- 现在卖与以后卖的佣金费率、最低佣金、税率、每股滑点，以及增量融资利息。未知不要写成 0。零成本教学必须标明
- 窗口结束仍未触及边界：未解决
- 两边都碰到时的先后：未解决
- 算术：增量净额、盈亏平衡门槛。门槛不是概率
- 证据：
- 结构：本次未评估结构 / 另节已写
- 执行：
- 总结论：证据或模型不完整时必须包含「检查不完整」。真实期望不能估计时写「无法估计」。不得把正的条件增量写成继续持有指令

## 复盘

本次不做就写「本次不填写」。细节用 [复盘卡](../../docs/templates/review.md)，不改计划快照。

- 价差相对所写成本和成交：费用未知就不要写成已审计净盈亏
- 当时有效的规则是否被遵守：
- 规则本身是否要改：无 / 提议新版本（不回改旧快照，不用后来的行情重写当时的结论）

## 用词核对

- 总结论是否在该包含「检查不完整」时包含了它：
- 是否把保护参考写成保证成交，或写成必须守到才能退出：
- 是否用截止后才知道的内容改了当时的句子：
- 是否出现下单指令，或新买入已经通过：
