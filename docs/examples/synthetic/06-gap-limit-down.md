# 合成示例 06：跳空跌停

本页是合成的，不是行情。冻结 as-of：合成日 D 09:25 Asia/Shanghai。规则版本 `2026-11-14.2`。

计划快照 v1 已写明：A 股，调用方填写的板块涨跌幅限制 10%，最小申报单位 100 股，可卖数量 100。保护参考 10.00，依据是合成日 D-1 已完成的回踩低点。快照里的卖出设想是「若跌破 10.00 再考虑卖出」。该快照本页不修改。

开盘证据：

- 来源 URL：`https://example.invalid/synthetic/open-limit`
- 检索时间：合成日 D 09:25 Asia/Shanghai
- 数据 as-of：合成日 D 09:25
- 会话：开盘集合竞价结果，不是常规收盘
- 单位：元，股
- 复权或公司行为口径：不复权
- 摘录：开盘 9.00，并处在调用方所写的跌停价；10.00 没有成交
- 规则版本：`2026-11-14.2`

数据足够说明这次不能在 10.00 成交。结构没有出现更高的已完成回踩低点。

- 数据结论：数据足够、仍新且口径一致
- 结构结论：尚不可上移保护参考
- 执行结论：计划按现行规则不可执行
- 总结论：计划按现行规则不可执行

保护参考 10.00 不是已经卖出的价格，也不是必须守到才可以考虑退出的价位。跌停之后按开盘后的实际结构重估。若涨跌幅限制或最小申报单位当时是空白，卖出可行性应写成「检查不完整」，而不是本页这种已经写明规则后的不可执行。

阻断性缺口：把「在保护参考价卖出」当成可以执行的计划。非阻断缺口：无。
