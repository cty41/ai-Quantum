# 合成走查

这些文件全部是合成的。`synthetic: true`，不是行情，也不是新闻。价格、时间和证券代码都是为了走通 [交易记录](../../trade-record.md) 而写的。不要把它们引用成市场记录，也不要把其中的数字写成普遍门槛。

冻结的 as-of 写在每页开头。每页都分开写数据、结构和执行三问，并有一行总结论。不完整或不可执行的例子，总结论不是放行。

| 文件 | 要看的失败或齐备 | 总结论 |
| --- | --- | --- |
| [01 走查](01-complete-walkthrough.md) | 数据齐、口径已选定、规则已填写 | 结构尚可，可继续观察 |
| [02 融资缺失](02-missing-financing.md) | 卖压判断缺融资 | 检查不完整 |
| [03 未解决的 20 日窗口仍去算倍数](03-unresolved-window-multiple.md) | 口径未解决却报了倍数 | 检查不完整 |
| [04 过期或冲突](04-stale-conflicting-sources.md) | 来源过期并且互相冲突 | 检查不完整 |
| [05 复权口径混用](05-mixed-adjustment-vwap.md) | 成交均价和价格不是同一复权口径 | 检查不完整 |
| [06 跳空跌停](06-gap-limit-down.md) | 保护参考价不能被假设成交 | 计划按现行规则不可执行 |

01 是从计划快照走到复盘的一条完整追加。02 到 06 只演示当次检查为什么不能读成放行。仓库没有安装命令或测试命令；这些页供人阅读对照。
