# 能力盘点

整理日期：2026-11-13。这一页只补仓库里原先没有的盘点。收盘、融资、同业、成交均价和保护参考的操作步骤已经在 [流动性修复技能](../skills/liquidity-repair/SKILL.md) 和 [指标字典](../skills/liquidity-repair/indicators.md)，这里不重复那些配方。

一次即席抓取不等于已经打包的工具。工作区没有发现可独立分发的完整检查脚本，因此本仓库不收录脚本。下面「已有工具」指讨论中用过的能力，不是本仓库里的软件包。脚本细节现在无法复原，不能据此写成当时没有做任何取数。

## 已有工具

这些是历史能力，不是现成安装包，也没有在本次新增程序。

| 能力 | 讨论中用过的部分 | 限度 |
| --- | --- | --- |
| 公开网页行情对照 | 曾用腾讯行情、东方财富报价或日 K、新浪行情做收盘和盘中对照 | 页面可延迟、缺数或失败。关键数字要双源。没有可分发脚本，也没有官方实盘终端 |
| 收盘量能 | 约 15:15（Asia/Shanghai）读取已完成日 K 的开高低收、相对近 20 日的量、影线和是否假破 | 没有冻结倍数。原始规则是有形态才提醒。每日三只量能对照是后续扩展，不是已部署任务 |

| 隔夜与盘后 | 交易期间用人工核对把常规收盘和盘后分开 | 不是已接通的实时新闻。方法现在在盘前技能里 |

## 可升格提示词

这些检查已经反复使用。适合写成输入输出约定，不适合各建一个技能。

| 约定 | 现在放在哪里 |
| --- | --- |
| 截止时间、来源状态、事实 / 推断 / 缺口、建议与自述与券商核验分开 | [证据约定](evidence-contract.md)。本次新写入 |
| 收盘量能、融资、同业与成交均价、保护参考上移和首次跌破 | 已在流动性修复技能和指标字典。本次不重写 |
| 复盘时的成本口径、未结费用和无法正式计算的波动 | [复盘卡](templates/review.md)。本次补充分级 |
| 开盘前先做隔夜检查，再做当日结构 | 两份技能开头的调用关系。盘前检查不代替价量 |

状态用语仍用「结构尚可，可继续观察持有」「承接转弱」「结构破坏」「数据不足」，不用颜色简称。

## 缺失能力

| 缺口 | 说明 | 本次做什么 |
| --- | --- | --- |
| 券商成交与费用核验 | 没有交割单、精确成交时间和卖出费用、利息时，不能做绩效审计 | 只在复盘卡里留空。不做成交易技能 |
| 可分发的只读取数适配 | 取数曾经即席发生，但没有稳定脚本可放入仓库 | 记录为以后的缺口。现在不新增脚本或安装接口 |
| 实时新闻或盘中电报 | 现有做法是到截止时点核对已经打开的页面 | 继续用盘前技能。不写成黑天鹅预测 |
| 已授权的官方行情接口 | 可见实践是公开网页 | 有授权后再替换来源，输出约定保持不变 |
| 冻结规则后的样本外检验 | 一次有记录的买卖不能证明统计优势 | 仍是研究流程，不是新技能 |
| 宿主例程的定义副本 | 宿主侧另有三条正在使用的例程。本仓库没有它们的导出定义 | 不能因为仓库里没有调度文件，就说宿主侧没有任务。不修改这些例程，不记录接收人或标识 |

公开钟点示例仍只在两份技能的示例配置里：盘前名义 08:30、融资约 09:00、收盘约 15:15（均为 Asia/Shanghai）。它们是例子，不是这三条宿主例程的定义，也不是完成保证。
