# ai-Quantum

数个交易日至数周的短线观察与复盘纪律。这里记录如何核验数据时段、只用已完成 K 线，以及如何把价格、成交量、同业和急跌前历史交易区域的剩余空间放在一起看。入场、继续持有和退出分开写。已有仓位的保护参考，只在确认出更高的有效回踩低点之后才上移。

这是一套分析纪律，不是已经验证能够盈利的策略，也不构成下单授权。一次交易的结果不能证明存在统计优势。

## 命名

仓库名 `ai-Quantum` 来自对索罗斯量子基金这一名称的联想。这只是命名。本仓库与量子基金没有隶属关系，不构成背书，策略、杠杆、组织或业绩都不可比。

## 边界

- 适用窗口是急跌之后数个交易日到数周的流动性修复观察，以及同一窗口里对已有仓位的动态保护和事后复盘。低估或错杀一类想法若要观察，也得先写明持有窗口和假设，再用价格结构、同业和风险约束检验。「跌得多」本身不是机会，这一扩展也还没有另一套已验证规则。
- 长期基本面只用来检查持有窗口内有没有突发重大负面。盈利预测、供给改善等更长周期的条件，不能直接当成短线入场条件。
- 短线观察与长期价值研究分开。本仓库不收录价值研究材料。
- 观察频率不是交易频率。固定间隔的检查不能代替止损，也不会自动下单，也不能把一次碰价当成必须卖出。
- 本仓库没有交易软件、行情程序、回测框架、自动下单或代理流程。文中的检查步骤是给人执行和记录的。
- 若以后要讨论统计优势，须事先冻结规则，在多个事件、多个标的上做样本外检验，并计入 T+1、滑点、税费、融资利息和无法成交。
